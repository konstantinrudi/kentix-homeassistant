# Security policy

This integration can control alarm groups and physical doors. Treat security reports involving authentication, authorization, token handling, webhook exposure or unintended door operation as sensitive.

Do not publish a vulnerability report containing working credentials, access records, private network details or a reproducible exploit against an identifiable installation. Contact the repository owner privately through the security-reporting mechanism enabled on GitHub. Until an owner is configured, do not open a public issue containing sensitive details.

Use a dedicated, least-privilege Kentix account. Door control is disabled by default and should remain disabled unless explicitly required.
